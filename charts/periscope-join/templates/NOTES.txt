Periscope — join credentials created on THIS cluster.

  ServiceAccount : periscope/periscope-reader
  ClusterRole    : cluster-reader (read-only)
  Token Secret   : periscope/periscope-reader-token

Next: register this cluster on the HUB.

1) On THIS cluster, capture the (external) API URL and token:

     API_URL=$(oc whoami --show-server)
     TOKEN=$(oc -n periscope get secret periscope-reader-token \
       -o jsonpath='{.data.token}' | base64 -d)

2) On the HUB cluster, create the labeled Secret. Its NAME is the cluster name
   shown in the matrix (e.g. "prod-emea"):

     oc -n periscope create secret generic <CLUSTER_NAME> \
       --from-literal=apiURL="$API_URL" \
       --from-literal=token="$TOKEN"

     oc -n periscope label secret <CLUSTER_NAME> periscope.io/cluster=true

   Optionally set the column order (lower = further left in the matrix;
   unlabeled clusters sort to the right, then alphabetically):

     oc -n periscope label secret <CLUSTER_NAME> periscope.io/order=10

The hub watches for Secrets labeled "periscope.io/cluster=true" and picks this
cluster up automatically. Use the external API URL (not the in-cluster service)
so certificate reporting reflects the endpoint clients actually use.
